# `@isxn/isbn-ranges`

![Node.js](https://img.shields.io/node/v/@isxn/isbn-ranges?label=Node.js&logo=nodedotjs)

The package contains [ISBN range messages](https://www.isbn-international.org/range_file_generation) converted from XML into JSON.

## Installation

```sh
npm i @isxn/isbn-ranges
```

## Usage

```typescript
import data from '@isxn/isbn-ranges' with { type: 'json' };
```
